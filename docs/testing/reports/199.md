## 1. Scope
- **`gatecells.Classify(cell, budgets)`:** a pure function. Unreachable cells give `unreachable`. A cell past the current `max_search_radius_m` gives `beyond`. Otherwise the reach is `sweet_spot` (≤ `sweet_spot_budget_s`), `outer_ring` (≤ `outer_ring_budget_s`) or `beyond`. Separately, `InTimerZone` is set only when the whole cell is inside `zone_radius_m` (centre plus one edge) and its road time plus the time to cross one edge at `straight_line_speed_kmh` ≤ `timer_length_s − timer_zone_margin_s`.
- **`ReadBudgets`** reads those seven settings (the five budgets, `straight_line_speed_kmh` and `max_search_radius_m`) plus the grid's cell edge, and refuses a missing one.
- **`Tiers(ctx, q, grid, gateHistoryID, settings)`** places every cell of the newest build, and returns the build and the budgets used, for G25 later.
- **Migration 0049** adds `timer_zone_margin_s` (0 to 120, starting at 15) and `outer_ring_budget_s` (30 to 3600, starting at 300). It locks the table, adds each column with a default so global rows get the value, then clears the value the default stamped on zone override rows, with the append-only trigger paused for that one statement. Zone rows end exactly as they were.
- **Cross-checks in `geo`:** the margin must be under the timer, and the outer ring must reach the sweet spot. They apply globally and in every zone.
- **Import direction:** `gatecells` takes settings through a small `Getter` interface (which `geo.Effective` meets), so it never imports `geo`.

## 4. Independent review
- **First pass: FAIL.** Findings, all fixed:
  1. **0049 stamped zone overrides,** and the new cross-check could then refuse a valid global change. It now clears the stamp at once. `tests/db/tier_settings_test.go` runs 0048, adds a zone override, runs 0049 and checks the row is unchanged. The same flaw in the older settings migrations is recorded in `known_downsides.md`.
  2. **"Conservative" was overstated:** only the centre is routed. The whole cell must now be inside the circle, plus the time to cross one edge. The test checks every corner of every timer-zone cell against the real distance. A median or one-way splitting a cell is stated as not covered (G20).
  3. **Weak tests:** the no-rebuild test now checks each budget (sweet spot, timer, margin, outer ring, search radius) strictly, and the circle test is independent of the formula.
  4. **Tiers ignored a shrunken search radius.** Past it now counts as beyond.
- **Second pass:** PASS. No new findings. Note: at the lowest crossing speed allowed (3 km/h) one edge takes about 91 s, so the timer zone is empty, which errs on the safe side.

## 5. Known limits
