## 6. Known limits
- A crash between a handler's commit and its reply cannot lose the action, but a handler that forgets `Save` can still repeat it if it crashes before the fallback. That is logged as a bug.
- A NUL character in a reply cannot be stored, so that request returns 500.
- Queued rider actions do not use this middleware. Their key is the `event_id`, tracked per rider, and that is built with offline sync.
- Purging old rows is listed in the data map, and runs when the worker exists.
- Outbox events that keep failing retry hourly forever, and need an alert when monitoring exists.
