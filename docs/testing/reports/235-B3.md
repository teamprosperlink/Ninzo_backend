## 2. Decisions made while building
- **Quarantine reuses the hub's model.** `lots.status = 'quarantined'` is the status every stock count already skips (availability, order holds, remedies, restock suggestions all filter `l.status = 'ok'`), so nothing in `internal/availability`, `internal/orders/offers.go`, `internal/matching`, `internal/routing` or `internal/relocation` changed. On top of that the scooter's `on_hand` for the lot goes to 0 with one `quarantine` ledger entry (migration 0059 adds the reason), so the rider's stock list, stock count and shift summary stop counting it. The `scooter_stock` row stays, so a scan says `lot_quarantined`.
- **Who:** `lots.quarantined_by_rider` (a hub lead's stays `quarantined_by`; a check keeps it to one).
- **404 against 409.** A lot that does not exist, is on no scooter, or is on another scooter is 404, with the same reply for all three. `lot_not_on_scooter` is the rider's own lot that is not on the scooter now (all sold, or in their packed cassette). `lot_reserved` is a lot with reserved units.
- **Repeat.** The same rider asking again (any key) answers 200 with the first time and writes nothing. A later rider on the same scooter gets `lot_not_on_scooter`.
- **Where ops see it.** `listHubOps.quarantined_lots` also counts lots a rider quarantined that the hub packed (found by restock history). The hub's own lot list (partner app) does not show it: the lot is not at the hub.
- **checkGate.** No gate has a code in our data (customer gates, the console's gate edit and the contracts carry none), so every answer is the contract's "no code on record": `checked` false, `matched` true. No `gates.rider_code` was added, as no contract can set it. Only for an accepted, unreleased offer on an unfinished order, else 404.
- **Console list.** `GET /admin/quarantined-stock`, operation `listQuarantinedStock`, permission `orders.read` (admin, ops, support; hub_manager is refused). Reasons are the stored values (`temperature` means too warm). `order_ids` lists up to 20 orders that had units from the lot.
- **Timeline.** Source `stock`, kind `stock.quarantined`, for lots a rider quarantined on the order's scooter from one hour before the order was made until it ended (now, while open). Detail: lot, code, item, reason, units, `had_units_for_this_order`. The rider's note is never shown.

After the order gives its units back, asking again takes them out and answers 200. The rider's stock list now skips quarantined lots.
