## 1. Scope
- **Migration 0047** adds two tables, with guard triggers:
  - `gate_cell_builds`: one row per build of a gate version, with its road data version, grid, radius and cell count. It is append-only; the only allowed change is setting `redacted_at` once with nothing else changed.
  - `gate_cells`: the cell id, the straight-line metres, and the road seconds and metres, both null when the cell is unreachable. Cells are never changed, and are deleted only once their build is redacted.
- **`internal/gatecells`:**
  - `Candidates`: the cells whose centre is within the radius.
  - `Build`: one OSRM table call, many cells to the gate. It refuses any answer that is not from OSRM, and refuses a build where nothing reaches the gate.
  - `Store` (COPY), `Latest` (the newest build that is not redacted, on the right grid), and `Redact`.
- **`cmd/gatecells -local|-remote build|build-all`:** the radius comes from the gate zone's `max_search_radius_m`. `build-all` takes each gate's newest version that is not erased and has no build on that road data.
- **`geo.RedactGates`** also redacts cell builds.
- **Lists updated:** the data map and schema registries, the package lists in the Taskfile and CI, and the CI `routes` job, which now also runs the cell-set golden.
- **Test moved:** the routing-and-geo distance check moved from `internal/routing` to `internal/geo/distance_test.go`. `geo` now depends on `routing` through `gatecells`, so keeping the check in `routing`'s tests made an import cycle. The check itself is unchanged.

Two first runs failed. Both were fixed in the code or the test, never by weakening a rule:
- **The ring count:** the candidate test's brute-force scan found `r=3000: {15 -10} missing`. Ring k reaches only 1.5 × edge × k across the flat sides, not √3 × edge × k, so the builder now uses 1.5. The deliberate break below proves the test catches the old count.
- **Truncate:** the service login is refused TRUNCATE outright (42501) before the trigger can fire. The test accepts that stronger refusal for truncate only.

The cell-set golden's first bound (at least 10 cells within 80 s) was a guess. It is now true invariants: no cell within 80 s lies further than the 40 km/h cap allows, the 80 s set is not empty, and nothing is faster than the cap. The measured counts are recorded in w2.

## 3. Deliberate breaks
Each break was made alone, the tests run, then the code restored (checked with `cmp`).

| Break | Caught by |
|---|---|
| Ring count with √3 (too few rings) | `r=3000: {15 -10} missing` |
| Placeholder straight lines stored as road times | `a straight-line answer: <nil>` |
| Erasure keeps the cells | `builds 2, redacted 2, cells left 50` |
| The build guard lets any update through | `change a build: ... got <nil>`, `redact and change: ... got <nil>` |
| `Store` without its re-check of the gate version | `moved: <nil>` |
| No insert guard | `a build for an erased gate version: ... got <nil>`, `a cell from another grid: ... got <nil>` |

## 4. Independent review
- **First pass: FAIL.** All findings are fixed:
  1. **Privacy race.** A build reads the pin, then OSRM takes seconds or minutes, so an erasure in between could be followed by exact cells. Fixed in two places. `Store` now locks the gate version (`FOR SHARE`, which waits for or blocks erasure's update) and re-checks that it is not erased and is where the cells were built from (`ErrGateChanged`). Insert triggers also refuse a build for an erased version, a build that starts redacted, cells for an erased build, and cells from another grid.
  2. **`build-all` stopped at the first bad gate.** It now reports each failure, carries on, and fails at the end; a one-gate build returns its own error.
  3. **Erasure was not proven end to end.** New tests: `TestErasureRemovesTheGatesCellSets` goes through `geo.RedactGates`; `TestBuildAllSkipsErasedGatesAndCarriesOnPastAFailure`; `TestStoreRefusesAnErasedOrMovedGate`; `TestCellsMustFitTheirBuild`.
  4. **Grid prefix not tied to the build.** The insert trigger now checks it.
- **Noted, not changed:** no production code calls `geo.RedactGates` yet (only tests). Recorded on #185.
- **Second pass:** PASS. The race is closed both ways, the insert triggers hold, and build-all carries on past a failed gate.
