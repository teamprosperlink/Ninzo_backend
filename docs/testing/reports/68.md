# Test report: menu (#68)

- Date: 2026-11-07

## Scope
`menu_items`, `price_history` with a trigger that records every price, `listMenuItems`, `getMenuItem`, and three test items through `cmd/testdata`. The real items come from the owner later, and the console changes them.

## Commands run
```
$ go test -count=1 -p 1 ./internal/catalog/ ./cmd/testdata/ ./tests/db/
$ go test -count=1 ./tests/contracts/ ./internal/mockserver/
```

## Scenarios
| Rule | Tested |
|---|---|
| Only items on sale are listed, in menu order, with every contract field | Yes |
| One item: hidden, unknown and malformed IDs get 404, and a sign-in is needed | Yes |
| An empty menu is an empty list | Yes |
| Every price is kept with its reason, a name change is not a price change, and history cannot be rewritten | Yes |
| Free, foreign-currency, non-HTTPS photo and unknown-status items are refused | Yes |
| Test items are added once, and a real item is never touched | Yes |

Deliberate breaks and the review are in the PR.
