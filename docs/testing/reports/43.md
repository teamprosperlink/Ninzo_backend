## 6. Known limits, for later steps
- **Real SMS must send through the outbox and always reply 200.** Sending during the request takes longer for a registered number, which reveals who is registered.
- **Lockout:** anyone can use up a number's 5 requests an hour. This needs the owner's decision, with #39.
- **Guessing odds** across many numbers need the IP limits in #39 before launch.
- **Test mode** opens any number with the fixed code, so staging must hold test data only.
- **A phone change, when built, must take the phone lock first.**
- Production cannot start until an SMS provider exists. This is deliberate.
