## 1. Scope
- **Migration 0045** adds `road_data_versions`: one row per OSRM build. It is unique on (extract sha256, profile sha256, image, algorithm), has CHECK rules on every field, is append-only (UPDATE, DELETE and TRUNCATE refused), and has RLS on with no policies.
- **`internal/roaddata`:**
  - `Parse` reads `build.json`. Every field is checked, and a bad field is named in the error.
  - `Register` stores a build once (`INSERT ... ON CONFLICT DO NOTHING`, then `SELECT`). A repeat answers the same id and changes nothing.
  - `List` returns the stored builds.
- **`cmd/roaddata -local|-remote register <build.json>|list`** checks the file before any database is touched, and uses the same target checks as the other commands. `task geo:roaddata:register` registers a build in the geo Postgres (5433).
- **Lists updated:** the data map row (v1.0.0), `builtInV100` in the schema test, and the database test lists in the Taskfile and CI.
