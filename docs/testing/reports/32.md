## 6. Known limits
- `sslmode=require` encrypts but does not check Supabase's certificate. To decide at the staging deploy.
- Railway's drain time must be at least 25 seconds for a clean stop. Set and check it at the staging deploy.
- How the Supabase pooler reports a wrong password is unverified, so the stop-at-once rule is proven only on Postgres itself.
- Three database tests skip locally if `task db:migrate` has created `ninzo_service` on that server, and say how to get a full run. In CI they fail instead of skipping.
- `TestRunEndToEnd` picks a free port, and another program could take it first. The test then fails with a clear message.
