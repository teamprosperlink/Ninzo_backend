## 1. Scope
A new CI job, `routes`, in `.github/workflows/ci.yml`:
- runs `bash tools/osrm/build.sh test` (the committed test-zone extract)
- serves it with `deploy/compose.geo.yml` (compose profile `osrm`) and waits until OSRM answers
- runs `go test -count=1 -v -run Golden ./internal/routing/` with `ROUTING_TEST_URL=http://localhost:5001` and `REQUIRE_ROUTING_TESTS=yes`, so a skipped run fails instead of passing

The geo README's merge rule now names five checks.
