# Test report: an expired confirmed suggestion raises the hub's seq (#192)

## What was fixed
`ExpireUnaccepted` (internal/restock/restock.go) ends a confirmed request that no hub accepted within `restock_accept_s`. For a request that began as a suggestion, `bumpRider` treats the expired request as the rider's draft and skips the hub's seq, so the hub app kept showing it. The natural expiry now raises the hub's seq for `source = 'suggested'`, as `CancelTx` and the console's `ExpireTx` (#149) do. A manual request still raises it once, through `bumpRider`.
